# Veterinaria San Marcos

Proyecto desarrollado para la Evaluacion Parcial 1 de Desarrollo Fullstack II.

## Descripcion

Sitio web para la Veterinaria San Marcos que permite consultar informacion de la veterinaria, revisar servicios, registrarse, iniciar sesion y solicitar citas.

Tambien incluye funciones internas para usuarios con permisos administrativos.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- LocalStorage
- Git
- GitHub

## Funcionalidades

- Registro de usuarios
- Inicio de sesion
- Validacion de formularios
- Consulta de servicios
- Solicitud de citas
- Gestion de citas
- Gestion de usuarios
- Control de roles
- Consulta de medicamentos y vacunas en stock
- Diseño responsivo
